This folder is a COPY of UI source files only. The main project was not modified.

Structure
---------

react-portal/
  MustHeader/          Header + mega-menu (MustHeader.tsx, MustHeader.scss, navigation.data.ts)
  HeroSlider.tsx       Photo slider + pill links menu over the slider
  Footer.tsx           Footer component
  Footer.scss

angular/
  shell/header/        Site header + nav (header.component.*)
  shell/footer/        Site footer (footer.component.*)
  shell/hero-banner/   Hero / background photo slider (hero-banner.component.*)
  shell/quick-nav-links/  Pills + dropdown menus on the hero (quick-nav-links.component.*)
  shell/data/
    navigation.data.ts Mega-menu data (MENU_ITEMS) — same content the header consumes in the live app.
  core-support/
    constants/hero-banner-settings.ts   Key used for hero images from site settings API
    utils/api-url.util.ts               Helper used by hero-banner for /uploads/ URLs
  dashboard-home/      Page that hosts <app-hero-banner> on the dashboard (includes hero-slider-related SCSS)

Notes
-----
- Angular header.component.ts imports MENU_ITEMS from "../../../core/data/navigation.data" in the project.
  In this snapshot the menu data file lives at src/app/shared/shell/data/navigation.data.ts — adjust paths
  when you integrate this copy elsewhere.
- React and Angular share similar concepts but are separate apps; copy the folder that matches your target stack.
